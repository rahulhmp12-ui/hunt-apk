# Hunt

Termux-এ এক ট্যাপে কমান্ড চালানোর লঞ্চার। পারমিশন ও উইজেটের ঝামেলা ছাড়া।

## ব্যবহার
1. Termux ইনস্টল থাকতে হবে।
2. অ্যাপ খুলে "Run commands in Termux" পারমিশন Allow করুন।
3. একবার "Termux প্রস্তুত" চাপুন।
4. কমান্ড লিখে সেভ করুন, ট্যাপ করে চালান।

## বিল্ড
GitHub Actions → build → hunt-debug-apk আর্টিফ্যাক্ট।
